# Product Roadmap — El Arca Market

## Fase 1 (Completada): MVP Base
- POS ultra rápido con idempotencia y tickets.
- Inventario Kardex y costeo por promedio ponderado.
- Control de caja y cuadre diario.
- Asistente de IA con Vercel AI SDK + Google Gemini API determinista.

## Fase 2 (Próxima): Ampliación Multisucursal
- Soporte para múltiples sucursales y varias cajas simultáneas.
- Entrada de mercancía por fotografía (Visión Multimodal con Gemini).
- Registro por voz continuo con Gemini Live API.
